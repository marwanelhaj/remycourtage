# Rémy Leroi – Landing page (Ziassur)

Site statique publié avec GitHub Pages.

```
index.html          page principale
assets/css/style.css  styles
assets/js/main.js     scripts (CONFIG du cabinet en haut du fichier : CFG, REVIEWS)
assets/img/           images (logo, og-image…)
.nojekyll           désactive Jekyll sur GitHub Pages
```

Pour modifier le téléphone, l'e-mail, GTM, etc. : éditer `CFG` au début de `assets/js/main.js`.
